01 / HIGH-LEVEL DESIGN

4me trong hệ sinh thái

Các dịch vụ là đối tượng chính trên sơ đồ: logo, thiết bị, database cylinder và bucket thay cho các hộp component.

Core: một desktop nhật ký cho mỗi thành viên; Tonight khám phá cộng đồng; note/reaction/guestbook; Messenger; Ink và nghi thức mỗi đêm.

Integrations: Google xác thực; Resend gửi mail; Apple tìm/preview nhạc, YouTube embed và Last.fm; dữ liệu và ảnh do API quản lý.

02 / SYSTEM ARCHITECTURE

Request paths & data ownership

Tách các đường gọi công khai, thao tác thành viên qua web server và kênh realtime.

Trust boundary: session cookie chỉ thuộc web. Next.js xác minh uid/sessionVersion rồi gọi API với bearer token. Upload và private live topics dùng HMAC ticket 10 phút.

State: PostgreSQL lưu users, entries, chat, notifications, moderation. Bucket lưu JPEG. Hub phát sự kiện qua WebSocket; không phải kho lưu lịch sử chat.

Implementation details

Mở từng sơ đồ để xem module, endpoint và thứ tự xử lý.

03 · Component architecture

Chi tiết module bên trong ba runtime; đây là monorepo với hai app triển khai, không phải chín microservice.

Shared contracts: Zod input schemas, Entry/Me/Chat types, safe text markup, HMAC upload/live tickets, night dates and prompts. Database calls stay inside API. Client state and animation engines run in the browser.

Code evidence: apps/web/components/*, lib/*; apps/api/src/app.ts, routes/*, lib/*; packages/shared/src/*

05 · Authentication & trust boundary

Luồng đăng nhập mật khẩu và kiểm tra phiên ở lần thao tác tiếp theo.

Cookie có chữ ký chứa uid, sv, exp. getMe() kiểm tra chữ ký/hạn rồi đọc version hiện tại từ API; đổi mật khẩu hoặc log off everywhere tăng version. Google OAuth là luồng riêng: code flow + PKCE/state, không nằm trong sequence mật khẩu này.

Code evidence: apps/web/app/welcome/actions.ts; apps/web/lib/auth.ts, crypto.ts; apps/api/src/routes/internal.ts.

06 · Publish & notify

Đường ghi một trang công khai mới, từ Notepad đến thông báo người theo dõi.

Luồng này mô tả POST tạo mới. Bản nháp/riêng tư không phát bài ra Tonight. Thư niêm phong chờ cron mở. Hiện PUT chuyển bài thành public chưa dùng cùng luồng announce; sơ đồ không giả định lỗi đó đã được sửa. Publish dùng waitUntil, không phải message queue bền vững.

Code evidence: apps/web/lib/writer-actions.ts; apps/api/src/routes/internal.ts; lib/notify.ts; live/hub.ts.

07 · Media pipeline

Ticket, xử lý ảnh, quota và hai nơi lưu: object bytes trong bucket, ownership trong database.

Khi đọc ảnh: GET /media/* → Cloudflare edge cache → S3 store nếu cache miss. Hiện route ảnh dùng cache public một năm và không kiểm tra session; bucket private không đồng nghĩa URL ảnh yêu cầu đăng nhập. Trang được lưu tối đa 12 ảnh.

Code evidence: apps/web/components/PhotoPicker.tsx; lib/writer-actions.ts; apps/api/src/routes/media.ts, lib/media.ts.

08 · Realtime & private topics

Handshake WebSocket, cấp quyền topic và fan-out sự kiện.

Hub duy nhất lấy bằng idFromName("hub"); hibernation giữ WebSocket và auto ping/pong. Đây là kênh gửi sự kiện/presence. Lịch sử chat và notifications nằm trong PostgreSQL, không nằm trong bộ nhớ Hub.

Code evidence: apps/web/lib/live.ts, live-actions.ts; apps/api/src/routes/live.ts, live/vet.ts, live/hub.ts.
